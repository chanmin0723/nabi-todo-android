# 나비 할 일 — 안드로이드 앱

웹 앱(나비 할 일)과 **같은 Firebase 프로젝트(todo-657ec)의 같은 달력**을 읽고 씁니다. 폰에서 고친 내용은 웹에, 웹에서 고친 내용은 폰에 실시간으로 반영됩니다. 여기에 시간이 되면 울리는 알람을 더했습니다.

## 📥 설치 (로그인 필요 없음)
폰에서 이 링크를 열면 최신 APK가 받아집니다:
https://github.com/chanmin0723/nabi-todo-android/releases/latest/download/nabi-todo.apk

설치 후 앱의 설정 → 🔄 자동 업데이트에서 "설치 허용"을 켜 두면, 새 버전이 올라올 때마다 앱이 6시간마다(그리고 앱을 열 때) 확인해서 스스로 설치합니다. 첫 업데이트 때 한 번은 "설치할까요?" 확인 창이 뜨고, 그다음부터는 묻지 않는 경우가 많습니다(Android 12+, 기기에 따라 가끔 확인 창이 뜰 수 있음).

## 기능
- 웹의 공유 코드·링크로 참여, 또는 앱에서 새 달력 만들기(웹에서 그 코드로 참여 가능)
- 일 보기(날짜 이동, 진행률, 기한 지난 일) / 나중에 보기
- 할 일 추가·수정·삭제, 체크, 하위 할 일, 반복(매일·평일·매주·2주마다·매월·매년), 반복 일정의 "이 날만 건너뛰기", 그룹, 중요도, 메모
- **알람**: 할 일에 시간과 알림(정각/10분/30분/1시간 전)을 정하면 그 시각에 알람 알림이 뜨고, 버튼으로 **완료** 또는 **10분 뒤 다시**를 누를 수 있습니다.
- **못 끝낸 일 알림**: 매일 정한 시각(기본 21:00)에 그날 끝내지 못한 일과 기한이 지난 일을 한 번 알려 줍니다.
- **콕 찌르기**: 오늘 할 일 옆 `👉 콕`을 누르면 같은 달력을 쓰는 상대 폰에 "○○님이 '할 일' 하라고 콕 찔렀어요" 알림이 갑니다(알림의 완료 버튼으로 바로 체크). 할 일 하나당 하루 한 번만 보낼 수 있고, 설정에서 내 이름을 정합니다. 상대 앱이 꺼져 있어도 15분마다 확인하므로 몇 분~십수 분 늦을 수 있습니다(절전 모드에서는 더). 웹은 콕 알림을 받지 못합니다.
- 오프라인에서도 기록되고, 연결되면 자동으로 올라갑니다. 앱이 꺼져 있어도 알람은 울립니다.

## 배포 구조
`main`에 push하면 GitHub Actions가 APK를 빌드해 Releases(`v1.0.<실행번호>`)에 올립니다. 앱의 versionCode가 실행번호라 새 릴리스가 자동으로 "더 새 버전"이 됩니다. 서명키(`app/nabi-todo.keystore`)는 업데이트가 덮어 설치되도록 저장소에 고정해 두었습니다(개인용, 키가 공개되어 있으니 Play 스토어용으로는 쓰지 마세요).

## 빌드 방법 (Android Studio)
1. Android Studio(최신)에서 이 `nabi-android` 폴더를 **Open**합니다. Gradle 동기화가 끝날 때까지 기다리세요(처음엔 몇 분).
2. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 연결한 뒤 ▶ Run. APK가 필요하면 Build → Build APK(s).
3. 앱을 처음 열면 알림 권한을 허용하세요. 설정(톱니바퀴)에서 **5초 뒤 테스트 알람**으로 알람이 정상인지 확인합니다.

`google-services.json`은 필요 없습니다. 웹과 같은 설정 값을 `app/build.gradle.kts`에 넣어 직접 연결합니다.

## 웹과 연결하기
- 웹에서 공유한 달력: 앱 위쪽 달력 이름 → "공유 달력 참여" → 코드나 링크 붙여 넣기
- 앱에서 만든 달력을 웹에서: 설정에서 코드 복사 → 웹 계정 메뉴 "공유 달력 참여"에 붙여 넣기

## 알람이 안 울릴 때
- Android 12 이상: 설정 → 앱 → 나비 할 일 → "알람 및 리마인더" 허용
- 배터리: 이 앱을 "제한 없음"으로 설정(제조사 절전 기능이 알람을 막는 경우가 많습니다)
- 알림 채널 "할 일 알람"의 소리가 꺼져 있지 않은지 확인

## 알아 둘 점
- 코드를 아는 사람은 누구나 보고 고칠 수 있습니다(웹과 같은 방식).
- 알람은 앞으로 14일치를 미리 걸고, 앱을 열 때와 6시간마다, 재부팅 후에 다시 맞춥니다. 웹에서 시간을 바꾼 일정은 그때 반영됩니다(앱이 켜져 있으면 즉시).
- 월간 달력 화면은 아직 없습니다(일 보기에서 날짜를 눌러 이동).
