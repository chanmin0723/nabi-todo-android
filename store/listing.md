# Play 스토어 등록 정보 (복사해서 붙여넣기)

## 앱 이름 (30자 이내)
나비 할 일

## 간단한 설명 (80자 이내)
친구와 같은 달력을 함께 보고, 시간이 되면 알람이 울리는 고양이 투두 앱

## 자세한 설명
삼색 고양이 나비가 지켜보는 할 일 달력이에요.

■ 친구와 같은 달력
달력 코드 하나로 친구와 같은 일정을 실시간으로 함께 보고 고쳐요. 오프라인에서 적어도 연결되면 자동으로 맞춰져요.

■ 알람
시간과 알림(정각·10분·30분·1시간 전)을 정하면 그 시각에 알람이 울려요. 알림에서 바로 '완료'하거나 '10분 뒤 다시'를 누를 수 있어요. 그날 못 끝낸 일은 저녁에 한 번 알려 줘요.

■ 콕 찌르기
친구의 할 일을 보다가 '콕'을 누르면 상대 폰에 알림이 가요. 할 일 하나당 하루에 한 번만 보낼 수 있어서 부담 없이 쓸 수 있어요.

■ 홈 화면 위젯과 잠금 화면
- 주간 위젯: 한 주의 날짜별 할 일 제목을 한눈에
- 월간 위젯: 날짜별 남은 일 표시
- 잠금 화면: 오늘 할 일을 알림이나 배경 그림으로 표시

■ 그 밖의 기능
반복(매일·평일·매주·2주마다·매월·매년), 하위 할 일, 그룹, 중요도, 메모

■ 알아 두세요
- 달력 코드를 아는 사람은 누구나 그 달력을 보고 고칠 수 있어요. 믿는 사람에게만 공유하세요.
- 광고가 없고, 할 일 내용은 달력 동기화에만 사용돼요.

## 앱 콘텐츠 설문 답안 가이드
- 광고: 아니요
- 앱 액세스: 제한 없음(로그인 없음). 달력 코드는 앱에서 새로 만들 수 있음
- 대상 연령: 13세 이상(아동 대상 아님)
- 콘텐츠 등급(IARC): 폭력·성적 콘텐츠·도박 없음, 사용자 간 상호작용 있음(공유 달력, 콕 알림)에 '예'로 답변
- 뉴스 앱 아님 / 정부 앱 아님 / 금융 기능 없음 / 건강 앱 아님

## 데이터 보안 양식 답안 가이드
- 데이터 수집: 예 / 데이터를 제3자에게 공유: 아니요 (Firebase는 처리 위탁(서비스 제공자)로 간주되어 '공유'에 해당하지 않음)
- 전송 중 암호화: 예 / 데이터 삭제 요청 방법: 개인정보처리방침의 연락처 이메일
- 수집 항목
  - 앱 활동 > 기타 사용자 생성 콘텐츠(할 일 내용): 수집됨, 앱 기능, 필수
  - 개인 정보 > 이름(선택 입력한 표시 이름): 수집됨, 앱 기능, 선택
  - 기기 또는 기타 ID(앱이 만든 무작위 값): 수집됨, 앱 기능
- 광고 ID·위치·연락처·사진·결제 정보: 수집 안 함

## 권한 신고 사유 (민감 권한 양식에 입력)
- 정확한 알람(SCHEDULE_EXACT_ALARM): 사용자가 정한 시각에 할 일 알람을 울림(핵심 기능)
- 배경화면 설정(SET_WALLPAPER): 사용자가 켠 경우에만 잠금 화면 배경에 오늘 할 일을 표시
